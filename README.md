# Madhusudhanan R — Portfolio

React + TypeScript + Vite + Tailwind CSS v4, built from the Figma file "Portfolio" (Desktop - 1).

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build into dist/
```

Edit your content in `src/content/` (profile, projects, caseStudies, api, architecture).
Add real repository links in `src/content/projects.ts` (`repoUrl`).
